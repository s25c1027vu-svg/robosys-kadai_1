- Python
 - python3.XX

##このコマンドについて
- このコマンドは作業時間と休憩時間を管理するためのコマンドです。
- 標準入力として"作業時間(min)" "休憩時間(min)""セット数(回)"を与え実行すると、作業時間と休憩時間をメーターで表示し管理してくれます。
- 入力例(作業時間：25分、休憩時間5分：、セット回数2回の場合) ：$ echo "25 5 2" | ./coffee_break.py
